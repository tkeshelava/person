# Person Management

A lightweight application for managing person records.

## Features

- Create, read, update, and delete person records
- Store person data including name, age, contact information, etc.
- Filter and search capabilities
- Data validation

## Getting Started

### Prerequisites

- .NET 8.0
- Database (SQL Server)

### Installation

```
git clone https://github.com/tkeshelava/person.git
cd PersonManagement
dotnet restore
dotnet build
```

## Usage

Run the application:

```
dotnet run
```

## Configuration

See `appsettings.json` for configuration options.
